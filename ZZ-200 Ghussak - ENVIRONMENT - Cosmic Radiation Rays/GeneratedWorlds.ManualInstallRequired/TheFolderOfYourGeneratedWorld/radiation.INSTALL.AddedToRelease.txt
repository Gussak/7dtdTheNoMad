Cosmic rays code only work if you install this file.

Find out the size of the world in pixels at the file splat3.png, or based on the folder name like 10k 8k 6k, of the world you want to apply this mod, if it is Navezgane or other pregen, look inside the main game folder like ".../7 Days To Die/Data/Worlds/Navezgane".

Rename the original ex.: radiation.png to radiation.Original.png.

Copy the correct size radiation_*_CosmicRays.png there.

Then, rename ex.: radiation_x6144_CosmicRays.png to radiation.png or create a relative symlink/shortcut file to it.
